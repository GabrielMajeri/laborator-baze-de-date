# Materiale laborator baze de date

## Descriere

Acest proiect conține fișierele sursă pentru materialele didactice folosite în cadrul laboratorului de baze de date pe care îl țin la [Facultatea de Fizică](https://www.fizica.unibuc.ro/Fizica/Main.php) a [Universității din București](https://unibuc.ro/) (anul II Robotică și anul III Fizică Informatică).

Materialele sunt scrise în [Markdown](https://en.wikipedia.org/wiki/Markdown) și transformate într-un site static folosind [Zensical](https://zensical.org/). Varianta compilată a resurselor poate fi găsită [aici](https://gabrielmajeri.ro/laborator-baze-de-date).
